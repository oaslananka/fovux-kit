# Fovux 1.0.0 Release Notes

Fovux 1.0.0 is the initial public release of the local-first edge-AI computer vision workbench.

## Headline Wins

- **Secure local HTTP transport:** every endpoint except `/health` now requires a bearer token in
  `FOVUX_HOME/auth.token`, tool calls are rate-limited, and the server can run UNIX-socket-first on
  Unix systems.
- **More truthful exports and training lifecycle:** ONNX parity no longer reports false success,
  training writes deterministic params plus `pid.txt`, and `metrics.jsonl` is the primary live
  metrics schema.
- **Daily-use Studio UX:** Fovux Studio includes live webviews, a training launcher, run stop/resume/
  delete/tag actions, comparison views, and export history visibility.
- **Expanded tool surface:** 9 new tools for dataset augmentation, model distillation, ensemble
  inference, visual comparison, run archiving, MLflow sync, active learning, and training adjustment.
- **Cross-package compatibility contract** enforced at runtime in fovux-studio against fovux-mcp.
- **12 granular Language Model Tools** registered by fovux-studio.
- **First-run walkthrough** covering install, profile, server, doctor, dashboard, and dataset.
- **System Health (Doctor) sidebar** and privacy badge in fovux-studio.
- **MCP Registry manifest, Smithery manifest**, and discovery badges.
- **Sigstore signing and SLSA provenance** for release artifacts.
- **Cross-OS CI** with macOS and Windows backend matrix, fuzzing, and path-traversal tests.

## Breaking Changes

- Start HTTP explicitly for Studio on TCP while the extension transport is finalized:
  ```bash
  fovux-mcp serve --http --tcp --metrics
  ```
- HTTP clients must send the bearer token:
  ```bash
  curl -H "Authorization: Bearer $(cat ~/.fovux/auth.token)" http://127.0.0.1:7823/runs
  ```
- Rotate a leaked local token with:
  ```bash
  fovux-mcp rotate-token
  ```
- Training metadata now stores runtime PID in `pid.txt`; do not depend on `params.json.pid`.
- `train_start` now rejects unsafe duplicate runs by default; use `force=true` to override.
- HTTP tool invocation applies per-tool rate limits.

## Upgrade Path

```bash
cd fovux-mcp
uv sync --locked --extra dev
cd ../fovux-studio
pnpm install --frozen-lockfile
pnpm verify
```

See `fovux-mcp/docs/upgrade/v2.md` for the full migration guide.
