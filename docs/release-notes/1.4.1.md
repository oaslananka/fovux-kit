# Fovux 1.4.1 Release Notes

> **Status:** Planned security and reliability patch. These notes do not indicate that packages
> have been published.

## Security

- Raise the runtime Pillow floor from `12.2.0` to `12.3.0`, addressing the published Pillow
  advisories reported by the repository's `pip-audit`, OSV, and Trivy dependency scans.
- Constrain the security-sensitive MCP SDK dependency to `>=1.28.1,<2`, replacing the affected
  `1.28.0` lock entry while keeping Fovux on the supported MCP v1 line.
- Preserve Torch `2.12.1`; the separate Torch `2.13.0` compatibility upgrade is not part of this
  security patch.
- Record a time-bounded OSV exception for the Setuptools advisory reachable only through the
  optional Torch 2.12.1/YOLO lock path. Removing that exception is tracked in issue #134 and
  requires the separate Torch 2.13 compatibility upgrade.
- Enforce the configured `CRITICAL,HIGH` threshold when Trivy emits SARIF; without the explicit
  action input, SARIF mode scans all severities and incorrectly fails the gate on the tracked LOW
  optional-Torch advisory.

## Verification Evidence

The remediation is complete only when the release pull request records successful results for:

- `uv lock --check`;
- frozen dependency installation;
- runtime requirements export plus `pip-audit --strict`;
- OSV and Trivy dependency scans;
- the repository `ci-required` and `security-required` checks.

This patch supersedes the single-package MCP update in Dependabot PR #124 while preserving that
commit's authorship in the remediation branch history.
